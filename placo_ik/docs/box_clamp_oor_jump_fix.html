Box Workspace Clamp — OOR 大範圍跳變修復報告

2026-07-24 · placo_ik/ik_node/ws_boundary.py — SoftClamp._apply_box()
OOR = Out Of Range（超出範圍）　—　VR tracker 換算出的末端目標某一軸超出 workspace box 邊界（raw < lo 或 raw > hi）的狀態，程式中即 BoundaryState.outside == True， console 亮紅色 [OOR]。本次修復處理的正是舊版 box clamp 在 OOR 附近的跳變。

1症狀

啟用矩形 box clamp（--ws-clamp，未給 --ws-mesh）後，末端目標一旦接近或 超出邊界，下令位置會在「邊界面」與「session 參考點 base」之間大範圍來回跳變。 VR tracker 只要在邊界附近輕微抖動，就會被放大成劇烈跳動。

2根因（兩缺陷疊加）

缺陷 A — dx *= g 把整段位移往 base 收，而非停在邊界

舊碼 new = base + g·dx。越靠近邊界 g → 0，下令位置不是停在邊界， 而是塌回 base（session 參考點，可能離邊界很遠）。

右手 x 軸範例：base=0.30, hi=0.50, margin=0.05

tracker 推到 raw_xd_near_hig = (d/0.05)²舊版下令 new_x
0.450.051.000.450
0.480.020.160.329
0.50（貼邊界）0.000.000.300

手往外多推 3cm（0.45→0.48），下令位置反而往回彈 12cm；推到邊界直接彈回 base。

缺陷 B — 平方 gain 非單調，出界後「重新打開」

g = (d/margin)² 對 signed distance 是對稱拋物線，最小值 0 在邊界， 越過邊界後 d 變負、平方又變大 → clip 回 1.0：

距邊界 d−margin0（邊界）+margin
g1.0（clip）0.01.0

單步 delta 夠大直接跳到「界外 > margin」時，g 回到 1.0 → 完全不衰減 → new = base + dx（遠在界外）→ 再被 np.clip 硬 snap 回邊界面。

疊加 → 跳變

tracker 抖動讓 raw 在「界內 g≈0（塌回 base）」和「界外 g=1（snap 到邊界面）」之間切換， 下令位置就在 base ↔ 邊界面 之間大幅來回。

3轉移曲線：raw 目標 → 下令位置

右手 x 軸（base=0.30, hi=0.62, margin=0.05）。橫軸為 tracker raw_x，縱軸為實際下令 new_x。

舊版（塌回 base 後 snap 到邊界 → 跳變） 新版（平滑飽和、單調、恆 < hi） y = x（未 clamp 參考）

舊版紅線在 raw≈0.62 附近俯衝到 0.30（塌回 base），出界後又垂直 snap 到 0.62 — 這道 V 形落差就是跳變。新版綠線一路單調上升並飽和收斂於邊界內側。

4修復：位置式（position-based）平滑飽和

不再縮放增量位移，改成把 raw 目標位置經過平滑「飽和」映射。每軸獨立，上界為例（下界對稱）：

over = raw - (hi - margin)               # >0 一旦進入 margin 帶
enc  = margin · over / (over + margin)   # ∈ [0, margin)，帶入口斜率 1 → 遠處 → 0
new  = (hi - margin) + enc               # 嚴格 < hi

解決了什麼

  • 不依賴 base/dx → 不塌回參考點（消除 A）
  • 對 raw 單調 → 界外只是更貼邊界，不反跳（消除 B）
  • C¹ 連續：帶入口斜率=1，無速度突跳
  • 恆在界內：enc < margin → 免 np.clip 硬 snap
  • 切向自由：未貼面的軸原樣通過 → 可沿邊界滑動

退化保護

若某軸 hi − lo ≤ 2·margin（兩側 margin 帶重疊，本專案 box 不會發生）， 退回硬 clamp 至中段。

6使用方式（cmd 不變）

本次只改內部數學與 console 提示，CLI 參數完全不變：

python3 placo_ik/ik_node/placo_ik_online_profiler_ws_mesh.py --arm right --ws-clamp

--boundary-margin（預設 0.05 = 5cm）：飽和帶寬度。調大 → 更早、更緩開始減速。

觸發時 console 彩色提示（BoundaryMonitor）： 🟡 [BOX] 減速中 🔴 [OOR] 目標出界 🟢 [OK] 解除
