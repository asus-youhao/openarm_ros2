# Left vs Right Arm IK 權重與 Limit 差異分析

> 分析 4 個 solver（pinocchio / pybullet / placo / pure_python）中  
> `_HUMAN_RIGHT` vs `_HUMAN_LEFT` 的差異，以及根本原因說明。

---

## 1. URDF 物理結構差異

LEFT arm 是 RIGHT arm 的**鏡像設計**，導致：

| 方向 | Right | Left | 描述 |
|------|-------|------|------|
| j1 旋轉軸 | `0 0 1` | `0 0 1` | 相同 |
| j2 旋轉軸 | `-1 0 0` (RPY +π/2) | `-1 0 0` (RPY -π/2) | 旋轉基準方向相反 |
| j7 旋轉軸 | `0 1 0` | **`0 -1 0`** | Y 軸反向 |
| j2 joint limit | [-10°, +190°] | **[-190°, +10°]** | 完全鏡像翻轉 |
| j1 joint limit | [-80°, +200°] | **[-200°, +80°]** | 完全鏡像翻轉 |

## 7. 已知差異整理（刻意設計 vs 待修正）

### ✅ 刻意差異（URDF 物理鏡像，必須不同）

| 差異 | RIGHT | LEFT | 原因 |
|------|-------|------|------|
| j2 pref | +0.700 | **-0.700** | URDF j2 完全鏡像，joint 正方向相反 |
| j2 hard limit | [0°, +190°] | [-190°, 0°] | URDF 鏡像 |
| j1 hard limit | [-80°, +200°] | [-200°, +80°] | URDF 鏡像 |
| j7 物理旋轉軸 | `0 1 0` | `0 -1 0` | 鏡像（但 limit 相同，系統自動處理） |

### ⚠️ 目前不一致（需注意的差異）

| 差異 | 發現位置 | 說明 |
|------|---------|------|
| j3 hard limit | pinocchio R=[-90°,+17°] vs L=[-90°,+17°] | ✅ 相同（修正後） |
| j3 hard limit | pybullet R=[-90°,+17°] vs L=[-90°,+90°] | ❗ **右臂 hi=0.300 限制 < 左臂 hi=1.571**（右臂刻意防止肘撞軀幹） |
| j3 hard limit | placo R=[-90°, 0°] vs L=[-90°,+90°] | ❗ **同上：右臂比左臂更限制** |
| j4 hard_lo | pinocchio R=0.250 vs L=0.000 | ❗ **右臂 min_elbow=14°（起來）, 左臂 min=0°** |
| pure_python j2 pref | R=+1.2735 | ❗ **與其他 3 個 solver R pref=0.7 不一致** |
| pure_python j6 limit | R=[-45°,+23°] | ❗ 非對稱（左臂是[-45°,+45°]）|
| pure_python j7 limit | R=[-46°,+29°] | ❗ 非對稱（左臂是[-90°,+90°]）|

## 9. Solver 間 j2_right pref 不一致問題

```
pinocchio  RIGHT j2 pref = +0.700 rad (≈ 40°)
pybullet   RIGHT j2 pref = +0.700 rad (≈ 40°)
placo      RIGHT j2 pref = +0.700 rad (≈ 40°)
pure_python RIGHT j2 pref = +1.2735 rad (≈ 73°)   ← 不同!
```

pure_python 的 right j2 pref 偏高（73°），表示 home 姿態肩膀抬很高。  
若 pure_python 與其他 solver 切換，姿態會有跳躍感。

**建議修正：** 統一改為 `pref=0.700`

## 10. 結論

| 項目 | 結果 |
|------|------|
| 兩臂 naturalness **weight** 是否相同？ | ✅ **完全相同**（4 個 solver 都是） |
| 兩臂可旋轉**範圍大小**是否相同？ | ✅ **完全相同**（URDF 鏡像，角度總量一致） |
| 兩臂 hard limit **數值**是否相同？ | ❌ **不同**（j1/j2 鏡像翻轉，這是正確行為）|
| j2 pref 是否鏡像？ | ✅ **正確**（R=+0.7, L=-0.7）|
| 各 solver j3 right limit 是否一致？ | ⚠️ **pinocchio/pybullet/placo 略有差異**（故意防碰） |
| pure_python right j2 pref 是否與其他 solver 一致？ | ❌ **不一致**（0.700 vs 1.2735）— 待修正 |
